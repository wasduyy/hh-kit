# Cursor Adapter

## Rules Generation

Cursor uses `.cursor/rules/*.mdc` files with YAML frontmatter.

## MCP Server Configuration

Cursor uses `.cursor/mcp.json`.

## Setup

1. Copy `.scaffold/adapters/cursor/rules-template.mdc` → `.cursor/rules/harness.mdc`
2. Copy `.scaffold/adapters/cursor/mcp-template.json` → `.cursor/mcp.json` (if Layer 1+)
3. Restart Cursor
